## 内容创作指南

### 1. 内容深度控制

根据演示类型调整内容详细程度：

**技术分享/会议演讲**
- 每个主题点：2-3个段落
- 包含：概念解释、代码示例、最佳实践
- 避免：过度简化、缺少技术细节

**商业路演**
- 每个要点：精炼的核心信息
- 包含：数据支撑、案例说明
- 避免：冗长描述、技术细节

**教学培训**
- 每个步骤：清晰的说明和示例
- 包含：练习建议、常见问题
- 避免：跳跃性讲解、缺少过渡

### 2. 内容结构

## 内容模板示例

### 技术分享示例

```markdown
## React Hooks 核心概念

### 核心内容

React Hooks 是 React 16.8 引入的新特性，它让你在不编写 class 的情况下使用 state 和其他 React 特性。Hooks 解决了 React 长期存在的几个问题：组件间逻辑复用困难、复杂组件难以理解、class 组件的困惑。

最常用的两个 Hooks 是 useState 和 useEffect。useState 允许你在函数组件中添加内部状态，而 useEffect 让你能够执行副作用操作。这两个 Hooks 覆盖了大部分常见的使用场景。

### 要点

- Hooks 只能在函数组件中使用
- 必须在组件顶层调用，不能在循环、条件或嵌套函数中调用
- 自定义 Hook 可以复用状态逻辑
- Hooks 向后兼容，可以逐步采用

### 代码示例

\`\`\`jsx
import React, { useState, useEffect } from 'react';

function UserProfile({ userId }) {
  // 状态管理
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  // 副作用：获取用户数据
  useEffect(() => {
    fetch(\`/api/users/\${userId}\`)
      .then(res => res.json())
      .then(data => {
        setUser(data);
        setLoading(false);
      });
  }, [userId]); // 依赖项：userId 变化时重新执行

  if (loading) return <div>加载中...</div>;
  return <div>{user.name}</div>;
}
\`\`\`

### 演讲备注

强调 Hooks 的三大优势：更简洁的代码、更好的逻辑复用、更容易理解的组件。可以询问听众是否使用过 class 组件，以便调整讲解深度。演示时可以打开 React DevTools 展示 Hooks 的状态。
```

我们的目标市场是中国的10-500人规模企业，这个细分市场有超过200万家企业，但只有不到5%采用了专业的协作软件。这代表着一个巨大的未开发市场机会。

### 要点

- **市场规模**：450亿美元（2023）→ 850亿美元（2028）
- **增长率**：13.5% CAGR
- **目标客群**：中国10-500人企业（200万家）
- **渗透率**：仅5%，增长空间巨大
